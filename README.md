**Wokfire Alley: Night-Market Cooking Rush** — run the busiest Indonesian street-food stall in town. Take orders from the board, pick ingredients from the counter, chop them on the board, fry them in the wok (and pull them out before they burn), build each dish on the plate, and serve before the ticket timer runs out. Five recipes (Nasi Goreng, Mie Goreng, Sate Ayam, Gado-Gado, Soto Ayam) unlock across rush waves; fast serves earn tips and combo bonuses. Earn Rp120.000 before closing time to win the shift — three failed orders ends it. Keyboard, mouse and touch controls, synthesised WebAudio sizzle, chops and serve bells, and all art drawn in code. No network, no assets, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or open `game/index.html` from any static server.
